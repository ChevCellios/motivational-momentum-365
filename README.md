[Otvori zasebnu stranicu](https://chevcellios.github.io/motivational-momentum-365/)

Fotorealistična AI ilustracija s programiranom animacijom rotora, zatvorenog toka energije, gadgeta i RGB ciglica. Ljudski likovi u ovoj izvedbi ostaju mirni. Perpetuum mobile je umjetnički koncept, ne fizički izvediv stroj.

GIF se ponavlja svakih šest sekundi. GitHubove osobne postavke pristupačnosti mogu zaustaviti automatsku reprodukciju.

<details>
<summary>Kako je animacija izrađena</summary>

Osnovna ilustracija generirana je uz pomoć AI-ja. Pokret je programiran u Pythonu, pomoću biblioteke Pillow otvorenog koda. Izrada animacije iz priložene ilustracije ne zahtijeva plaćeni servis ni API ključ.

Za ponovnu izradu GIF-a:

```sh
python -m pip install -r requirements.txt
python src/render.py
```

Izvorna ilustracija nalazi se u `assets/scene.png`, a kod u `src/render.py`. Promptovi i privatne radne bilješke nisu uključeni.

</details>
